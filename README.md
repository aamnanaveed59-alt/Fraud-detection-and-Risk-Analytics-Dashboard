# Fraud Detection & Transaction Risk Analytics Dashboard

## 📌 Project Overview

This project presents an interactive **Power BI dashboard for fraud detection and transaction risk analysis**.

The dashboard analyzes transaction-level data to identify fraud patterns, examine potential risk indicators, and communicate key findings through interactive visualizations and KPIs.

## 🎯 Objectives

* Monitor overall transaction activity
* Identify and analyze fraudulent transactions
* Calculate fraud rate and financial impact
* Compare fraudulent and genuine transactions
* Analyze fraud patterns across merchant categories
* Examine transaction-level risk indicators
* Present insights in a clear, business-friendly dashboard

## 📊 Dashboard Components

### KPI Metrics

* Total Transactions
* Fraud Cases
* Fraud Rate (%)
* Total Fraud Amount

### Visual Analysis

**1. Fraud vs. Genuine Transactions**
Compares fraudulent transactions with legitimate transactions to understand the overall transaction composition.

**2. Fraud Amount by Merchant Category**
Analyzes fraud-related financial impact across different merchant categories.

**3. Fraud Risk Factors**
Examines indicators such as foreign transactions and location mismatches to identify potentially higher-risk transaction patterns.

**4. Device Trust Score Analysis**
Explores the relationship between device trust scores and fraudulent transactions.

**5. Fraud Transaction Amount Distribution**
Analyzes how fraudulent transactions are distributed across different transaction-value ranges.

## 📈 Insights

The analysis provides a business-oriented view of fraudulent activity by examining:

* The proportion of fraudulent transactions within overall transaction activity
* Fraud-related financial impact
* Merchant categories associated with higher fraud amounts
* Transaction and device-level risk indicators
* Patterns that can potentially support fraud investigation and monitoring

> **Note:** The dashboard is an analytical project and should not be interpreted as a production fraud-detection system.
